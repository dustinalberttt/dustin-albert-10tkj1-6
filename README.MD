## Struktur Proyek
- `index.html`: Halaman utama portofolio.
- `components/`: Komponen UI (button-set, card, card-badge, navbar, sidebar, interactive).
- `pages/`: Halaman-halaman web (profile, about, contact, gallery, hero).
- `styles/`: File stylesheet eksternal.
- `assets/`: Gambar dan aset media pendukung.
